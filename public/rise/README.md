# Rise banner artwork

Drop files here and the banner switches from the drawn SVG to your art
automatically — no code change needed. Add them one at a time if you like;
anything missing is simply skipped.

| file               | what it is                                        |
|--------------------|---------------------------------------------------|
| `fighter-left.png` | swordsman mid-lunge, **facing right**             |
| `fighter-right.png`| swordsman mid-lunge, **facing left**              |
| `fx-left.png`      | left fighter's technique, sweeping left→right     |
| `fx-right.png`     | right fighter's technique, sweeping right→left    |
| `bg.png`           | optional backdrop (sky, cliffs, etc.)             |

**For it to look right**
- transparent background, no baked-in drop shadow
- fighters ~900px tall; techniques ~1600px wide
- each blade points toward the centre of the frame
- light both figures from the centre — that's where they collide

**Prompt that works well**

> anime key visual, lone swordsman mid-lunge facing right, katana extended,
> haori billowing, dramatic rim lighting from the right, full body,
> transparent background, no background, high detail, cel shaded

and for a technique:

> anime flame breathing technique, huge stylised fire wave sweeping left to
> right, ukiyo-e wave crests, orange and gold, transparent background

Use original characters. Don't ship copyrighted ones — this app is public.
